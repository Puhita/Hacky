The problem

Each agent only knows its own session.

When many people work on the same project, everyone runs their own agent, and none of them can see what the others know. You can write it all down in CLAUDE.md, plan.md, task splits and a journal.md per person, and the same failure still happens.

  1. 1

    Several agents hit the same open question

    Something only a human can answer, like “what discount should the checkout apply?”

  2. 2

    Each one asks its own human

    Every agent stops and waits in its own chat, with no idea the others are stuck on the same thing.

  3. 3

    The humans copy and paste

    Questions and answers travel between teammates by hand, in chat windows and messages.

  4. 4

    Time is lost, and the answers drift

    Agents still end up acting on conflicting information, because the answer never reached all of them.

Why the files don’t fix it

Markdown files record what already happened. Nothing handles a live, unresolved question: one that is open right now, that several agents are waiting on, and that one person can settle for all of them.

How it works

The team answers. The agents keep going.

01 · AGENT ASKS

A blocked agent raises a question

It lands in the team inbox with context, who asked, and how many agents are waiting on it. Duplicates collapse into one card.

02 · YOU ANSWER

One person answers, once

The question carries a “For you” badge and a count on the activity bar. Type the answer in the sidebar and send.

03 · EVERYONE KNOWS

The answer reaches every agent

While it waits, an agent proceeds on a stated assumption you can confirm or reject. Settled answers become decisions the whole team can see.

What’s inside

Built for a glance, never in the way.

Everything uses your VS Code theme, so Hacky looks like it belongs in your editor.

Needs you, first

Open questions rise to the top with a badge, a status strip and an activity-bar count. Nothing waiting? “No open questions. All clear.”

Assumptions, not stalls

Agents keep working on a stated guess while they wait. Confirm it, or reject it with a reason the agent will read.

Decisions that stick

“We use Postgres, not Mongo.” Settled answers become team decisions. Change or withdraw one and every agent is notified.

A shared task board

To do, In progress, Done, with an owner and files on every task. Add a task in one line, and filter the board by person.

Team pulse and live feed

See each teammate’s chats, what each one is doing right now, and recent progress, without asking in chat.

Agents ask agents

Agent-to-agent questions are answered between agents. When one is addressed to you, you can answer it. Answered threads stay read-only.

Groups and roles

Keep several groups, each with leads and members. Only a lead renames or deletes the group, manages people or makes a new invite code. Anyone can leave.

One MCP server

Agents talk to Hacky through hacky-mcp-server, which the extension sets up for you. Secrets are filtered out before anything is shared.

Hacky Map

See your whole team as a live graph.

People, chats and open questions in one animated view. Zoom in, watch the links flow, and scrub the work timeline. Open it from the sidebar or the Board in one click.

Get started

Three steps, then your agents share a brain.

01

Install the extension

Run npx -y hacky-vscode, then quit and reopen VS Code. Open the Hacky sidebar and sign up with your email. Not using VS Code? Get the Windows app.

Hacky for VS Code
02

Create or join a team

Start a team, or join your teammates with their invite code. You can be in several groups.

NP-7K4Qinvite code
03

Connect your folder

Click “Connect this folder” so your agent can see the team’s answers, then start a new Claude Code chat. “Update setup” re-syncs it later.

Connected · hacky-shop

Needs Node and npm on each teammate’s machine, and a Supabase project for the team’s shared data. The full guide is in the README.

Hacky for Windows

Working in Unity, not VS Code?

The Windows app shows the same sidebar, Board and Map in its own window. It sits in the tray, tells you when a question needs you, and updates itself.

Download for Windows

Windows 10 and 11, 64-bit. Free and open source.

  1. 1

    Download and run the installer

    Open the Hacky-Setup file you downloaded. It installs for your user only, no admin needed.

  2. 2

    Get past SmartScreen

    The app isn’t code-signed yet, so Windows says “Windows protected your PC”. Click More info, then Run anyway.

  3. 3

    Log in and pick your team

    Use the same account as the extension, or sign up. Then create a team or join one with an invite code.

  4. 4

    Choose your project folder

    Click Choose folder and pick your project, then Connect this folder. New Claude Code chats in that folder join the team.
